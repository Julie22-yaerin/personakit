# Post Types & Execution Rules

## 1. Câu chuyện cụ thể (Founders' Story)
- Hành trình, thất bại, khoảnh khắc nhận ra vấn đề
- **Mục đích**: tạo kết nối cảm xúc
- Cấu trúc: Bối cảnh → Xung đột/thất bại → Khoảnh khắc "aha" → Bài học mở (mời độc giả chia sẻ)

## 2. Ý kiến mạnh (Strong Opinion)
- Đi ngược số đông, tạo phân cực chiến lược
- **Mục đích**: tạo luồng thảo luận, tương tác cao
- Cấu trúc: Khẳng định gây tranh luận → Lập luận 3 điểm → Nhượng bộ hợp lý → Câu hỏi mở ra phe tranh luận

## 3. Phân tích/Tutorial (Tactical Teardown)
- Mổ xẻ cách làm, hướng dẫn từng bước
- **Mục đích**: khẳng định tính chuyên môn
- Cấu trúc: Kết quả trước → Quy trình từng bước → Công cụ dùng (lồng ghép sản phẩm ở đây như bước tối ưu) → Checklist tải về (lead magnet)

## 4. Nhận định ngành (Industry Observation)
- Góc nhìn vĩ mô về thị trường
- **Mục đích**: tạo độ tin cậy và tầm nhìn
- Cấu trúc: Dữ liệu/sự kiện → Diễn giải ý nghĩa → Dự đoán 12-24 tháng → "Kẻ thù chung" sẽ thua thế nào

# Execution Rules

- **Tần suất**: 3 bài/tuần (Thứ 2 – Thứ 4 – Thứ 6) → thuật toán đủ 48h phân phối.
- **4 giờ vàng**: phản hồi mọi bình luận trong 4 giờ đầu → hiển thị ×5–10.
- **Closing the loop**: luôn kéo traffic sang tài sản sở hữu (Email list, Discord kín) qua Lead Magnet giá trị cao (Template, Prompt Library, Blueprint).
