## Style Guidelines
- **Aesthetic:** Casual, minimalist, hand-drawn vector art style.
- **Line Work:** Use thick, confident, solid black outlines.
- **Coloring:** Flat, simple colors with minimal to no shading.
- **Features:** Exaggerated but recognizable founder features (glasses, hairstyle, specific clothing items) while maintaining the doodle abstraction.

The AI should mimic this exact visual language to ensure all generated founder avatars feel like they belong in the same unified system.
